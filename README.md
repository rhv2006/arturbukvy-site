# артурбуквы.рф

Сайт-визитка Артура Фаттахова: 3D, motion и key visual. Сделан на Astro, на выходе статический HTML в папке `dist/`.

## Команды

```bash
npm install      # один раз
npm run dev      # локально: http://localhost:4321
npm run build    # сборка в dist/
```

## Откуда берутся кейсы

Кейсы загружаются при сборке из RSS-ленты Behance `behance.net/feeds/user?username=rhv2006`: ссылка, обложка и дата.
Всё остальное настраивается в `src/data/cases.json`. Ключ — ID проекта из ссылки `behance.net/gallery/<ID>/...`.

| поле     | что делает |
|----------|------------|
| `title`  | Название. RSS отдаёт кириллицу знаками «?», поэтому русские названия берутся отсюда. |
| `tag`    | Метка на карточке: «3D · Motion», «Key visual»… |
| `top`    | Место в «Избранных работах» (1–6). Кейс без `top` попадает в «Ещё работы». |
| `hidden` | `true` — кейс не показывается на сайте. |
| `image`  | Своя обложка из `public/covers` вместо обложки с Behance. |
| `videos` | Пути к mp4 из `public/video`, которые проигрываются на карточке поверх обложки. |

Новый проект на Behance появляется на сайте сам после следующей сборки. Пока у него нет записи в `cases.json`, название собирается из адреса ссылки.

Если Behance недоступен во время сборки, сайт собирается из запасных `url` и `cover` в `cases.json`.

## Статьи

Блок «Статьи об автоматизации» загружается при сборке из RSS-ленты Teletype `teletype.in/rss/rhv2006`. Новая статья появляется на сайте сама после следующей сборки.
В `src/data/articles.json` настраиваются `order` (какие статьи идут первыми) и `hidden` (какие не показывать на сайте). ID статьи — последняя часть её адреса. Там же лежит запасная копия на случай, если Teletype будет недоступен во время сборки.

## Опыт

Блок «Опыт» — выжимка из резюме. Он редактируется вручную в массиве `experience` в начале `src/pages/index.astro`.

## Видео

Все видео лежат на самом сайте, в `public/video/`, сторонние плееры не используются: Vimeo из российской сети не открывается.

| файл | что это |
|------|---------|
| `reel-loop.mp4` + `reel-poster.jpg` | фон первого экрана: 6–21 с шоурила t2, без звука, ~1 МБ |
| `reel.mp4` | полный шоурил для кнопки «Смотреть шоурил», 1080p, ~11 МБ |
| `otp-1.mp4`, `otp-2.mp4` | баннеры ОТП на карточке кейса |

Исходники (`*.mp4` в корне проекта) в git не попадают. Пересжать после замены исходника:

```bash
ffmpeg -ss 6 -t 15 -i "t2 showreal 1min.mp4" -an -vf scale=1280:-2 -c:v libx264 -preset slow -crf 30 -pix_fmt yuv420p -movflags +faststart public/video/reel-loop.mp4
ffmpeg -i "t2 showreal 1min.mp4" -c:v libx264 -preset slow -crf 26 -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart public/video/reel.mp4
```

Видео на карточке кейса подключается полем `videos` в `cases.json`.
